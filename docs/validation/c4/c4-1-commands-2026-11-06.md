## İzole canlı Fortress koşusu

Mevcut ARM64 Humble/Fortress image'ları kullanıldı. C4.1, C1 doğrulayıcısı için C3.3.3 backend image'ını iki serviste de kullanır. Ortak SDF ve süreç supervisor'ı korunur. Simülasyon tarafı, `fleet.yaml` listesinden her robot için aşağıdaki executable'ı başlatır. `fleet_config` repo kökünden `PYTHONPATH` üzerinden sağlanır.

```sh
/workspace/install/fleet_battery_simulator/lib/fleet_battery_simulator/battery_simulator \
  --fleet-config /config/fleet.yaml --robot-id robot_1
```

```sh
export DDS_TEST_PAYLOAD=fleet-c41-battery ROS_DOMAIN_ID=65
compose_c41() {
  docker compose -p fleet-c41-battery \
    -f docker/compose/docker-compose.dds.yml \
    -f docker/compose/docker-compose.simulation-check.yml \
    -f docker/compose/docker-compose.simulation-c3-3-3.yml \
    -f docker/compose/docker-compose.simulation-c4-1.yml "$@"
}
compose_c41 config --format json
compose_c41 up --no-build --abort-on-container-exit --exit-code-from backend
# Kanıt alındıktan sonra
compose_c41 down
```

C4.1 kabulü için `ALL_C4_1_TESTS_PASSED`, `SIMULATION_SHUTDOWN` içinde `clean: true` ve iki container'ın 0/0 çıkışı denetlendi. `C41_GRAPH_VERIFIED` ve `C41_ENERGY_MEASUREMENT` JSON kayıtları topic ve enerji kanıtını taşır.

Dört koşunun her birinde kendi proje adıyla container inspect ve Docker kapanış olayları alındı. İlgili Compose katmanlarıyla yalnız bu test projeleri kaldırıldı.

```sh
project=fleet-c41-battery
for service in simulation backend; do
  name="$project-$service-1"
  docker inspect --format '{{.Name}} exit={{.State.ExitCode}} oom={{.State.OOMKilled}}' "$name"
  start=$(docker inspect --format '{{.State.StartedAt}}' "$name")
  finish=$(docker inspect --format '{{.State.FinishedAt}}' "$name")
  docker events --since "$start" --until "$finish" --filter "container=$name" \
    --filter event=kill --filter event=die \
    --format '{{.Action}} signal={{index .Actor.Attributes "signal"}} exit={{index .Actor.Attributes "exitCode"}}'
done

git diff --check
```

Host/Humble çıktıları, çözülmüş C4.1 Compose config, canlı loglar, dönüş kodları ve Docker incelemeleri yerelde `/tmp/fleet-c41/` altında tutuldu.
