## Fortress iki robotlu kabul

```sh
compose_c44() {
  docker compose -p "$DDS_TEST_PAYLOAD" \
    -f docker/compose/docker-compose.dds.yml \
    -f docker/compose/docker-compose.simulation-check.yml \
    -f docker/compose/docker-compose.simulation-c3-3-3.yml \
    -f docker/compose/docker-compose.simulation-c4-1.yml \
    -f docker/compose/docker-compose.simulation-c4-2.yml \
    -f docker/compose/docker-compose.simulation-c4-3.yml \
    -f docker/compose/docker-compose.simulation-c4-4.yml "$@"
}

run=c44-final
export DDS_TEST_PAYLOAD="fleet-$run" ROS_DOMAIN_ID=70
export C43_EVIDENCE_DIR="/tmp/fleet-c44/$run"
mkdir -p "$C43_EVIDENCE_DIR"
compose_c44 config --format json > "/tmp/fleet-c44/$run-config.json"
compose_c44 up --no-build --abort-on-container-exit --exit-code-from backend \
  > "/tmp/fleet-c44/$run.log" 2>&1
# Kaldırmadan önce Docker çıkış, OOM ve sinyal kayıtlarını al.
compose_c44 down
sqlite3 "$C43_EVIDENCE_DIR/c44.sqlite3" 'PRAGMA integrity_check; PRAGMA foreign_key_check;'
rg 'C44_PHYSICAL_CHARGE|C44_DOCK_DEPARTURE|ALL_C4_4_TESTS_PASSED|SIMULATION_SHUTDOWN' "/tmp/fleet-c44/$run.log"
```

İlk denemeler `c44-first`, `c44-pose` ve `c44-pose2` ayrı projelerdi. Temas sondası, Fortress'ın kendi `ign topic -i` ve `ign topic -e -n 1 --json-output` komutları ve ROS `ros2 topic echo --once /dock/dock_1/contacts ros_gz_interfaces/msg/Contacts` ile yapıldı. Ham loglar, geçici SDF ve SQLite dosyaları `/tmp/fleet-c44/` altındadır.

Aynı kabul `c44-final-repeat` ile bağımsız olarak tekrarlandı. Son host seçkisi `host-final.log`, tam Humble seçkisi `ros-final.log` içindedir. Humble testi `fleet-c44-ros` konteynerinde C4.3 komut ekindeki aynı image ve colcon adımlarıyla çalıştırıldı. C2.3 ve C3.3.3 config testleri ayrı pytest çağrılarıyla çalıştı.

`c44-regression-c43`, `c44-regression-c42` ve `c44-regression-c41` ilgili önceki Compose katmanlarıyla çalıştırıldı. Ana ve HIGH regresyonları şu komutları kullandı.

```sh
COMPOSE_PROJECT_NAME=fleet-c44-regression-c333 python3 scripts/run_c3_3_3.py \
  --domain 68 --token fleet-c44-regression-c333
COMPOSE_PROJECT_NAME=fleet-c44-regression-high python3 scripts/run_c3_3_3.py \
  --domain 68 --token fleet-c44-regression-high --high-preemption

for diagram in charging-queue-selection charging-exit-policy battery-wh-integration; do
  npx --offline --yes --package @mermaid-js/mermaid-cli@11.12.0 mmdc \
    -i "docs/diagrams/src/$diagram.mmd" -o "docs/diagrams/svg/$diagram.svg" \
    -c /tmp/fleet-c42/mermaid.json -b white
done
git diff --check
```

C4.3 regresyon kanıtı `/tmp/fleet-c43-recovery/c44-regression-c43/` ve HIGH kanıtı aynı kökteki `c44-regression-high*` dosyalarındadır. Diğer kapanış, log ve config kanıtları `/tmp/fleet-c44/` altında saklandı.
