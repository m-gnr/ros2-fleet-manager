## Temiz kabul profilleri

```sh
compose_c45() {
  docker compose -p "$DDS_TEST_PAYLOAD" \
    -f docker/compose/docker-compose.dds.yml \
    -f docker/compose/docker-compose.simulation-check.yml \
    -f docker/compose/docker-compose.simulation-c3-3-3.yml \
    -f docker/compose/docker-compose.simulation-c4-1.yml \
    -f docker/compose/docker-compose.simulation-c4-2.yml \
    -f docker/compose/docker-compose.simulation-c4-3.yml \
    -f docker/compose/docker-compose.simulation-c4-4.yml \
    -f docker/compose/docker-compose.simulation-c4-5.yml "$@"
}

export ROS_DOMAIN_ID=72
for repetition in 3 4; do
  for profile in energy charging; do
    run="c45-$profile-final-$repetition"
    export C45_PROFILE="$profile"
    export DDS_TEST_PAYLOAD="fleet-$run"
    export C43_EVIDENCE_DIR="/tmp/fleet-c45/$run"
    mkdir -p "$C43_EVIDENCE_DIR"
    compose_c45 config --format json > "/tmp/fleet-c45/$run-config.json"
    compose_c45 up --no-build --abort-on-container-exit --exit-code-from backend \
      > "/tmp/fleet-c45/$run.log" 2>&1
    # C4.3 komut ekindeki Docker inspect ve docker events sorguları burada çalışır.
    compose_c45 down
    sqlite3 "$C43_EVIDENCE_DIR/c45-$profile.sqlite3" \
      'PRAGMA integrity_check; PRAGMA foreign_key_check;'
  done
done
```

C4.5 enerji ve şarj profillerinin kabul işaretleri sırasıyla `ALL_C4_5_ENERGY_TESTS_PASSED` ve `ALL_C4_5_CHARGING_TESTS_PASSED`. Her projenin hem backend hem simulation çıkış kodu, OOM alanı, Docker sinyali, Nav2 ilerleme kaydı ve `SIMULATION_SHUTDOWN clean=true` işareti ayrı denetlendi.

İlk denemeler `c45-energy-first` ve `c45-charging-first`, ara tekrarlar `final-1` ve `final-2` ayrı proje ve SQLite dosyalarıyla saklandı. C4.1 ve C4.2 [önceki katmanlarıyla](c4-2-commands-2026-11-06.md#c41-ve-c42-canlı-fortress) `fleet-c45-regression-c41` ve `fleet-c45-regression-c42` olarak çalıştırıldı. C3.3.3 ve HIGH regresyonlarının ilk koşularında proje adlarında `-repeat` eki yoktu. Son tekrarlar şu komutları kullandı.

```sh
COMPOSE_PROJECT_NAME=fleet-c45-regression-high-repeat python3 scripts/run_c3_3_3.py \
  --domain 68 --token fleet-c45-regression-high-repeat --high-preemption
COMPOSE_PROJECT_NAME=fleet-c45-regression-c333-repeat python3 scripts/run_c3_3_3.py \
  --domain 68 --token fleet-c45-regression-c333-repeat
```

C4.5 ham logları, çözülmüş Compose config'leri, SQLite ve Docker kayıtları `/tmp/fleet-c45/` altında. HIGH regresyonunun ayrı log ve SQLite kopyası `/tmp/fleet-c43-recovery/` altındadır.
